# 🎓 Student Performance Analysis Dashboard

## Problem Statement

To develop a dashboard that analyses student performance data and presents key insights through clear summaries and visualisations, making performance patterns easier to understand.

## Objective

The objective of this project is to analyse student academic performance and present meaningful insights through an interactive Streamlit dashboard.

## Dataset

The project uses the Student Performance dataset from the UCI Machine Learning Repository.

- Dataset: Student Performance
- Repository: UCI Machine Learning Repository
- Dataset ID: 320
- Creators: Paulo Cortez and Alice Silva
- Year: 2008
- DOI: 10.24432/C5TG7T
- Dataset License: CC BY 4.0

The dataset contains information related to students' academic performance, demographics, study habits, attendance and family background.

### Dataset Attribution

Cortez, P. and Silva, A. (2008). Student Performance. UCI Machine Learning Repository. Dataset ID 320. https://doi.org/10.24432/C5TG7T
